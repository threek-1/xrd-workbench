# XRD Workbench

用于粉末 XRD 连续谱的本地工具。导入仪器导出的数值文件，处理谱线，与已有参考谱比较，并导出图谱和分析记录。

[English](README.en.md) · [中文使用教程](docs/TUTORIAL.zh-CN.md) · [分析方法](docs/METHODS.md) · [复现与质量检查](docs/REPRODUCIBILITY.md) · [开发路线](docs/ROADMAP.md)

![合成示例图谱](docs/demo-figure.png)

> 图中为程序生成的虚构演示谱线，不是实验数据或真实物相。已验证一组用户仪器文本与 TSV 的解析；尚未验证真实物相鉴定准确度。

## 可以做什么

- 批量导入 TXT / CSV / XY / DAT / TSV 连续谱；支持空白、逗号、Tab、分号分隔及显式列选择。
- 保留原始字节、SHA-256、解析规则、数据单位、波长声明和所有处理步骤。
- 角度裁剪、最大值/面积归一化；可选 AsLS 背景扣除与 Savitzky–Golay 平滑。
- 根据用户上传的标准谱库筛选候选：峰位一对一对应、轮廓相似度、未匹配峰、缺失参考峰、扫描范围覆盖和可选探索性平移。
- 展示峰位、峰突出度、半突出度宽度，以及已声明波长时的 d 间距。
- 分别生成实测单图（全部导入点与原始强度）和处理后的参考对比图。
- 填写参考化合物、化学式、结构、是否由 CIF 模拟和来源；未知项可以留空。
- 页面显示可下载的分析报告：主要峰的候选对应、多义归属、未匹配峰、参考排名与有条件的结构线索。
- 输出单栏/双栏尺寸的 PDF、SVG、600 dpi PNG/TIFF；支持叠加与上下错位排列、图例编辑。
- 一键下载原始数据、全部处理谱与峰表、候选证据、参数、软件版本、校验和与复现脚本。
- 本地网页与命令行共用独立 Python 分析内核；运行分析不需要云服务、API key 或大语言模型。

物相筛选限于用户提供的参考库。 文件名是候选标签，不是程序独立验证的化学身份。分数不是概率；不输出纯度、物相质量分数或未经验证的化合物名称。

## 快速启动

需要 Python 3.11–3.13。在本项目目录执行：

```bash
python -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -e .
xrd-workbench ui
```

浏览器打开 <http://127.0.0.1:8501>。默认显示明确标注的合成示例，点击 **运行分析并生成图谱** 即可体验。上传自己的数据时，关闭左侧的“使用合成示例”。退出终端中的服务按 Ctrl+C。

首次安装需要网络下载依赖；正常分析在本地进行。CLI 启动器绑定 `127.0.0.1` 并关闭 Streamlit 使用统计。此版本为本地单用户工具，不包含公网认证、配额或任务隔离。

### 是否需要 AI 或 API？

不需要。解析、寻峰、对比、绘图和报告均在本机完成。首次安装需要下载 Python 依赖；日常分析不调用模型或远程数据库。

### 输入格式

```text
# Sample A; 2theta in degrees; intensity in counts
2theta,intensity
5.00,107
5.02,108
5.04,111
5.06,109
5.08,112
```

- 输入必须是 **2θ / 度** 与强度，至少 5 个点；连续谱和峰列表不是同一种输入。本版不接收 PDF/图像或稀疏棒图作为连续参考谱。
- 兼容完整数值行末尾的单个逗号或分号（如 `5.00,107,`），并记录对应行号；不忽略中间缺失值或缺失的强度。
- 默认恰好两列。多列输入须在高级设置中指定角度/强度列（界面从 1 开始，Python API 从 0 开始）。若有数值型仪器头部，显式设置跳过行数。
- UTF-8/GB18030；小数点为 `.`，不支持小数逗号或带千分位的数值。
- 乱序数据会同步排序并记录；重复角度、NaN/Inf、数据区损坏行会拒绝，不会悄悄删除或合并。
- 每文件上限 20 MB / 200,000 点；网页单次最多 20 个样品与 40 个参考谱。每张图最多 8 条谱线。
- 波长未知时保留未知并提示；确认后才填入实际波长。默认数值 1.5406 Å 不是对仪器的自动识别。不同波长不能直接按 2θ 对比。
- 未实现专有 `.raw`、XRDML、CIF 或二维探测器图像；先从仪器软件导出数值连续谱。

### 命令行

```bash
xrd-workbench analyze "examples/Synthetic sample.csv" \
  --reference "examples/Synthetic Phase A.csv" \
  --reference "examples/Synthetic Phase B.csv" \
  --wavelength 1.5406 \
  --output runs/demo.zip
```

`--baseline`、`--smooth-window 11`、`--lower 5 --upper 65`、`--normalization area` 为显式选项。默认不扣背景、不平滑、不优化平移。CLI 面向常规双列文件；复杂列映射可用网页或 Python API。

## 如何理解结果

参考信息会作为“用户声明、未独立核验”进入报告。选择“由 CIF 模拟”仅记录来源，不会解析 CIF 或自动得到 hkl/空间群。未知物相保留未知；当前不是通过数据库自动鉴定未知化合物。

查看候选排名后，应打开 **候选与逐峰证据**：

1. 检查匹配峰是否足够、是否只覆盖一小段扫描范围。
2. 检查未匹配实验峰和缺失参考峰；这些都只是待解释的差异。
3. 检查波长、采样步长、背景、峰宽与样品条件是否可比。
4. 若启用平移，对照未经平移的分数。该平移不是仪器校准或晶格精修。

峰位 F1、轮廓余弦及覆盖比例是可解释的启发式指标，**并未以有标签的真实样品库校准或验证**。择优取向、展宽、背景、混相和参考库不完整都可能改变排名。该工具不执行 Rietveld、混相定量、晶体结构求解或 Scherrer 粒径报告。

## 图谱与可复现性

实测单图始终保留原始强度与全部导入点。对比图只对已处理谱施加记录在案的垂直平移，不会把匹配时优化的水平平移偷偷应用到成图。多谱图的编号和短标签在 manifest 中对应完整来源名称。负强度保留。图例建议使用短英文；缺少字形的标签会阻止导出。

每个 ZIP 包包含：

| 文件 | 内容 |
|---|---|
| `measurement/` | 实测单图四种格式、原始数值源表与独立 QA |
| `figure.*` | 对比图四种格式 |
| `report.md` / `report.json` | 当前出图样品的分析报告与结构化证据 |
| `reports/` | 所有分析样品的报告 |
| `raw/` | 上传的原始文件，逐字节保留 |
| `processed/` | 当前图中各条谱线的数据 |
| `analysis/` | 所有样品与参考谱的处理数据和峰表 |
| `comparisons.json` | 所有样品的候选排名、逐峰对应与警告 |
| `manifest.json` | 来源、单位、波长、参数、版本、显示偏移和 QA 范围 |
| `reproduce_analysis.py` | 从原始数据重做解析、处理、匹配及绘图 |
| `reproduce.py` | 直接由成图源数据重新绘图 |
| `checksums.sha256` | 除校验清单自身外的文件校验和 |

自动 PDF 检查覆盖文字尺寸、文字重叠和页面裁切；它不等于完成全部科研审查。开发流程另外使用 Nature Skills 的源码、PDF 字体、碰撞和适用的对齐检查，配置方法见 [质量检查](docs/REPRODUCIBILITY.md)。**不同数据和图例需要重新检查最终实际尺寸的成图。**

## 开发与测试

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
python -m build
python scripts/generate_demo.py
```

`src/xrd_workbench/` 中解析/处理、匹配、图谱和导出各自独立。CI 在 Python 3.11–3.13 上运行测试并构建包；本地验证结果见 [QA 记录](docs/QA.md)，不能把尚未运行的远端 CI 描述为通过。

本仓库只包含原创代码与明确标注的合成示例。不会附带用户原始实验文件、付费标准卡片或未授权参考数据库。示例可随源码使用；第三方输入的所有权与许可仍属于原来源。
