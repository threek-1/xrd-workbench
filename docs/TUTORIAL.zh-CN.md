# XRD Workbench 使用教程

本教程介绍如何导入连续 XRD 谱、与参考谱对比、检查主要峰，再保存图谱和分析记录。示例全部为程序生成的虚构数据，不对应真实化合物。

## 1. 先了解程序能回答什么

本程序适合已有测量数据和候选参考谱的场景。它能告诉你两条谱线有哪些峰对应、有哪些差异，以及在当前参数下哪个参考更相似。只有测量谱而没有参考时，也能绘图和寻峰。

程序不附带物相数据库，不会凭文件名识别化合物，也不执行晶体结构求解、Rietveld 精修或物相含量定量。报告中的结构线索来自参考谱及用户填写的信息。

粉末衍射中的峰位与晶面间距、辐射波长有关。一阶布拉格关系为 `d = λ / [2 sin(θ)]`；输入文件的横坐标是 **2θ**，计算时使用其一半。波长不明确时不要沿用默认值来计算 d。背景知识可读 [IUCr 的结构因子入门](https://www.iucr.org/what-we-do/education/pamphlets/introduction-calculation-of-structure-factors)。

## 2. 安装与启动

需要 Python 3.11–3.13。下面使用 Git 下载项目，再进入项目目录安装。请逐行执行；某一步出现错误时先处理该错误，不要继续后面的命令。

macOS / Linux（已安装 Git）：

```bash
git clone https://github.com/threek-1/xrd-workbench.git
cd xrd-workbench
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
xrd-workbench ui
```

Windows PowerShell 可以直接调用虚拟环境里的程序，无需修改脚本执行策略：

```powershell
git clone https://github.com/threek-1/xrd-workbench.git
cd xrd-workbench
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\xrd-workbench.exe ui
```

**安装命令必须在项目文件夹内执行。** `python -m pip install -e .` 最后的 `.` 表示当前文件夹，不是自动寻找下载的项目。安装前运行 `ls pyproject.toml`（PowerShell 用 `Get-Item pyproject.toml`），应能找到该文件。若找不到，先检查 `cd` 是否成功。

若下载的是 GitHub ZIP，先解压，再进入实际解压目录。例如，文件位于 macOS 的下载目录且名称为 `xrd-workbench-main` 时，运行：

```bash
cd ~/Downloads/xrd-workbench-main
```

然后执行上面从创建虚拟环境开始的命令，无需再次克隆。若路径不同，改用实际路径；已有项目也无需重复运行 `git clone`。

终端出现 `A new release of pip is available` 只是 pip 自身的可选更新提示，与本程序是否安装成功无关。无需为了启动程序升级 pip。若前面出现红色 `ERROR`，应以该错误为准；安装失败时继续运行会出现 `command not found`。

浏览器访问 <http://127.0.0.1:8501>。服务运行期间保留终端；结束时在终端按 Ctrl+C。若端口已被占用，可运行 `xrd-workbench ui --port 8502`，然后访问对应地址。

首次安装需要联网下载依赖。日常解析、计算、绘图和报告均在本机完成，无需连接远程服务。不要把启动地址改为公网监听后直接提供公共服务；当前程序按本地单用户使用设计。

## 3. 用合成示例跑完一次流程

1. 保持侧栏“使用合成示例”开启。
2. 先保留默认参数：最大值归一化、关闭扣背景与平滑、匹配容差 0.20°、不进行探索性平移。
3. 点击“运行分析并生成图谱”。
4. 打开“实测谱图”。在演示模式下，这张图展示的是完整的**合成样品**，并非实验测量。
5. 打开“对比图”，查看样品与两条参考谱的上下排列。纵向错位仅用于阅读，不代表负值、额外信号或浓度。
6. 打开“候选与逐峰证据”和“分析报告”，核对匹配峰及未匹配峰。
7. 在“对比图”下载完整 ZIP，再试着单独下载 PDF。

![合成示例对比图](demo-figure.png)

样品由虚构的 A、B 两套峰叠加背景与噪声生成。参考 A 的峰位包括 12.4、18.2、24.8、31.3、42.1 和 53.6°；参考 B 包括 10.8、20.6、28.1、36.7、45.9 和 59.2°。这些值来自示例生成代码，不能作为真实物相的标准峰位。

练习：仅选择 A 出图，再同时选择 A 与 B。注意“出图所选参考”与“用于分析的已上传参考库”不同：不画出某条参考，并不会把它从分析库中删除。

## 4. 准备自己的数据

从仪器软件导出连续的 2θ–强度数值文件。支持 TXT、CSV、XY、DAT、TSV；扩展名不能代替内容检查。

```text
2theta,intensity
5.00,107
5.02,108
5.04,111
5.06,109
5.08,112
```

这五行只是格式示意，不能代表足以进行物相比较的扫描。

| 项目 | 要求 |
|---|---|
| 横坐标 | 2θ，单位为度；不自动转换 θ、q 或 d |
| 纵坐标 | 有限数值；输入强度单位由原文件决定 |
| 分隔符 | 逗号、Tab、空白或分号 |
| 编码 | UTF-8 或 GB18030 |
| 小数点 | 使用点号 `.` |
| 长度 | 每条连续谱至少 5 点，最多 200,000 点；单文件不超过 20 MB |
| 重复角度 / NaN / Inf | 不接受；回查源数据 |

默认两列。超过两列时，在“解析、波长与高级参数”勾选手动指定列；界面列号从 1 开始。角度行乱序会同步排序，但不会改变角度与强度的配对。

完整数值行后多出的单个分隔符，例如 `5.00,107,`，可以读取，并记录行号。`5.00,,` 或中间缺失值不是同一种情况，不能通过删除空字段猜测。

如果仪器文件头包含数值参数，程序可能无法区分它与正式数据。此时根据文件内容设置“跳过样品开头行数”或“跳过参考开头行数”，不要为了消除错误随意增加跳过行数。

参考谱也须是连续数值谱。CIF 文件、PDF 卡片图片和只有离散峰位的棒图不能直接当成连续谱上传。

## 5. 导入与填写参考信息

关闭“使用合成示例”，分别上传实验样品和标准/参考谱。文件名必须唯一。一次最多 20 个样品和 40 个参考；当前出图选择一个样品，但所有已上传样品都会参与分析。

在“参考物相与结构信息”中填写已知内容：

| 字段 | 填写方式 |
|---|---|
| 化合物 / 物相名称 | 原始参考来源明确给出的名称 |
| 化学式 | 已知化学式；未知留空 |
| 结构说明 / 晶型 / 空间群 | 只填写已核实的信息，并在来源中注明依据 |
| 是否由 CIF 模拟得到 | 是、否或未知；不要仅凭文件名“计算”判断 |
| 来源 / CIF 编号 / 文献或数据库编号 | 能回溯到原始参考的标识或文献 |

填写内容会进入报告，但不会被程序自动核验。选择“由 CIF 模拟”只记录来源，不会读取结构、验证空间群或生成 hkl。参考名称未知时留空，报告会保留“物相名未知”。

## 6. 选择处理参数

第一次分析建议不扣背景、不平滑、不平移，先看原始谱线及其与参考的差异。

- **角度范围**：只影响分析、对比图和报告。实测单图保留全部导入点。先核对两条谱的共同范围，避免只比较恰好相似的一小段。
- **最大值归一化**：把保留区间内的最大强度设为 1，适合比较谱形。改变角度范围可能改变归一化除数。
- **面积归一化**：用保留区间的强度积分作除数。它不会给出物相含量；含负强度时采用带符号积分。
- **AsLS 背景扣除**：仅作用于样品，参数为算法设置。启用后与原始曲线对照，尤其检查宽峰是否被误当作背景。
- **Savitzky–Golay 平滑**：窗口按点数计算。过大的窗口可能改变窄峰。程序拒绝对不满足均匀采样要求的网格直接使用这两种处理。
- **峰突出度**：阈值相对于信号的最大值与最小值之差。提高阈值通常减少弱峰与噪声峰，但也可能漏检真实弱峰。突出度的定义见 [SciPy 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.peak_prominences.html)。
- **最小峰间距**：以角度为单位，限制相邻峰的保留距离。相邻反射可能因此被合并选择；应结合实际分辨率检查。
- **匹配容差**：允许实测与参考峰位的最大差值。放大容差可以增加偶然匹配，不能以分数变高为依据决定参数。

若知道波长，在高级参数中勾选“已确认波长”，分别输入样品与参考值。两者波长不一致时，程序拒绝直接进行角度空间比较。

“探索性参考平移”用于查看整体偏移对结果的影响，默认为 0。正值表示参考峰向较大的 2θ 移动。优化的平移只用于匹配记录，不会应用到图谱，也不能视为仪器校准或晶格变化的测定。

处理顺序和评分公式见 [分析方法](METHODS.md)。

## 7. 阅读结果

### 两张图的区别

| 结果 | 数据内容 | 适合用途 |
|---|---|---|
| 实测谱图 | 全部导入点、原始强度 | 检查原始谱形，保留测量记录 |
| 对比图 | 经过所选裁剪、处理和归一化的样品及参考 | 查看峰位和谱形差异 |

图例建议用短英文，避免导出字体缺少字形。原始中文文件名仍保留在记录中。图中不会自动标出所有峰号，以免遮住谱线；逐峰数值放在表格中。

### 分数和逐峰对应

评分由峰位 F1、轮廓余弦相似度和共同角度覆盖比例组合而成。它用于当前参考库内排序，**不是正确物相的概率**。0.8 不表示样品有 80% 的该物相。

查看排名后，至少检查：主要强峰是否对应；是否有明显未匹配实验峰；参考中的强峰是否缺失；两个扫描是否有足够的共同范围。只有一条参考时，“最高排名”也不代表已排除其他物相。

强度还受到结构因子、测量几何及样品制备等影响。相关背景见 [IUCr 粉末衍射教学：强度](https://journals.iucr.org/j/issues/2023/03/00/dv5004/)。本程序没有对这些因素进行完整建模。

### 分析报告

报告列出突出度最高的至多 10 个峰及其候选对应。它区分无对应、单一候选对应和多个参考同时对应。单个峰不能直接等同于某种元素，未匹配峰也不会自动标为杂相。

峰宽是**半突出度宽度**，不是经过峰型拟合和仪器展宽修正的 FWHM。两者的定义不能混用；见 [SciPy peak_widths](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.peak_widths.html)。不要把这一列直接代入 Scherrer 公式作为粒径结论。

结构段落是基于参考的候选解释，不会推算空间群、晶胞或原子连接。报告内容可作为检查记录；写入论文前需结合原始数据、参考来源及进一步晶体学分析。

## 8. 导出与复现

PDF、SVG 用于矢量图；PNG、TIFF 为 600 dpi。按最终排版选择宽度，再检查文字、细线和图例是否清楚。图中文字自动检查通过不等于科研结论已经验证。

完整 ZIP 包包含：

```text
raw/                     原始上传文件
measurement/             实测单图、源数据与检查记录
figure.pdf / .svg / ...  对比图
processed/               对比图源数据
analysis/                所有样品与参考的处理谱、峰表
report.md / report.json  当前出图样品报告
reports/                 全部样品报告
comparisons.json         逐峰对应和候选评分
manifest.json            参数、来源、版本及图形设置
checksums.sha256          文件校验和
reproduce_analysis.py     从原始文件重新分析
reproduce.py              由存储的成图数据重画
```

将 ZIP 解压到单独文件夹，激活已安装项目的环境后运行：

```bash
python reproduce_analysis.py
```

脚本重新读取原文件、处理、匹配、绘图并生成报告，同时核对与归档数据是否一致。也可运行 `python reproduce.py` 只重画两张图。依赖版本和 PDF 时间戳可能导致文件字节不同；关注数值、参数和图形内容的一致性。

导出包含有原始上传文件。与他人共享前先核对数据的公开范围；不要把私人分析 ZIP 直接提交到公开源码仓库。

## 9. 常见问题

| 情况 | 处理办法 |
|---|---|
| `does not appear to be a Python project` | 当前目录不含项目配置；先进入含 `pyproject.toml` 的项目文件夹，再安装 |
| `command not found: xrd-workbench` | 确认安装成功，并使用安装时的虚拟环境；重新打开终端后需再次激活环境 |
| `A new release of pip is available` | pip 的可选更新提示，可忽略；检查前面是否另有安装错误 |
| `ERR_CONNECTION_REFUSED` | 本地服务未启动或已退出；运行启动命令，待终端显示地址后访问，并保持服务运行 |
| `Ambiguous numeric header/data` | 查看所报行，确认实际数据起点；明确设置跳过头部行数 |
| 提示需要指定列 | 在高级设置选择角度列和强度列 |
| 缺失值、重复角度或非有限数报错 | 返回原文件核查；不要自动补零或平均 |
| 波长未知，没有 d 间距 | 确认仪器与参考条件；未知时保留未知 |
| 没有检出峰 | 检查是否为平谱、范围是否正确、突出度和间距是否过严 |
| 看起来相似但匹配分数低 | 查看峰位偏移、噪声、背景和扫描范围；先解释差异，再调整参数 |
| 图例导出失败 | 缩短图例，使用当前字体支持的字符，或选择较宽图幅 |
| 修改参数后结果没变 | 表单修改后须重新点击运行；结果区标注的是上次运行 |
| 只想绘制样品 | 不上传参考，或将出图参考选择清空 |
| 想上传 CIF / RAW / 图片 | 不支持这些输入；先提供有来源说明的连续数值谱 |

## 10. 提交问题或贡献

提交问题时附上软件版本、操作系统、参数、错误原文和最小可公开示例。原文件不方便公开时，优先提供保持相同头部和分隔符的合成文件，不要直接贴出未公开实验数据。

修改算法前请阅读 [METHODS.md](METHODS.md)，修改绘图后执行图形检查并查看实际尺寸输出。开发安装与测试：

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
python -m build
```
